Echo English — 音読・シャドーイング学習アプリ

【ファイル】
index.html : 画面
style.css  : デザイン
app.js     : 保存・再生・学習記録

【PCでの使い方】
3ファイルを同じフォルダに置き、index.htmlをChromeやEdgeなどで開きます。
「教材を追加」で英文とMP3を登録し、「学習する」で開始します。
再生ボタンを押すと、音声全体を繰り返し再生します。
学習を1回行ったら画面上部の「＋1 回記録」を押します。

【iPhoneでの使い方】
推奨: 3ファイルをHTTPSの静的Webホスティング（GitHub Pages / Netlify等）に配置し、Safariでアクセスします。
必要に応じてSafariの共有メニューから「ホーム画面に追加」を選択します。
ローカルのHTMLをiPhoneのファイルアプリから直接開く方法は、保存や音声再生が正常に動作しない場合があります。

【保存と注意点】
教材、MP3、学習回数はブラウザのIndexedDBに保存されます。
同じURLでも端末やブラウザが異なるとデータは共有されません。
ブラウザのWebサイトデータ削除やストレージ不足等で教材が失われる場合があります。
このバージョンにはバックアップ・同期機能はありません。元の英文とMP3を別途保管してください。
今日の回数は端末のローカル日付で集計し、累計は教材ごとに保存します。
再生回数は自動加算されません。「＋1 回記録」でのみ加算されます。
音声はユーザーが再生ボタンを押して開始します（iPhoneの制約）。
